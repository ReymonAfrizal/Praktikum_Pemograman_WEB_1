Fakultas Ilmu Komputer (FKOM)

Universitas Kuningan

Daftar Program Studi

1. Program Studi Sistem Informasi (S1)

Deskripsi: Mempelajari perancangan, pengembangan, analisis sistem informasi, serta tata kelola IT untuk mendukung proses bisnis organisasi.

Kompetensi: Analisis Sistem, Desain Web, Manajemen Basis Data, dan Enterprise Resource Planning (ERP).

2. Program Studi Teknik Informatika (S1)

Deskripsi: Memfokuskan pembelajaran pada rekayasa perangkat lunak, algoritma, kecerdasan buatan, dan arsitektur jaringan komputer.

Kompetensi: Software Engineering, Artificial Intelligence, Pemrograman Berorientasi Objek, dan Mobile App Development.

3. Program Studi Teknologi Informasi (S1)

Deskripsi: Berfokus pada pengelolaan infrastruktur teknologi, integrasi sistem, administrasi jaringan, dan keamanan siber.

Kompetensi: Sistem Administrasi, Keamanan Jaringan, Cloud Computing, dan Infrastruktur IT.
